# 在发布目录中调整软件

双击发布文件夹中的 `LocalDm.exe`。保留整个文件夹，运行不需要安装 .NET SDK。
从剧本库打开真实剧本（没有平板清单的旧版本会在开启时自动补，不新增版本），在「偏好设置 → 平板连接」点「开启平板连接」。
同一页会显示当前剧本的二维码和网址；电脑和平板连同一个 Wi-Fi。
第一次出现 Windows 网络访问提示时，允许专用网络。

| 要改的内容 | 在哪里改 | 何时生效 |
|---|---|---|
| 平板颜色、字号等样式 | `wwwroot/custom.css` 或 `reader.css` | 保存后刷新平板网页 |
| 平板阅读与分页脚本 | `wwwroot/reader-pagination.js`、`tablet-shell.js` | 保存后强制刷新网页 |
| 模型、音色、缩放 | 软件里的「偏好设置」 | 保存后生效 |
| 语音播放脚本 | `Voice/edge_speak.py` | 下一次朗读启动脚本时 |
| WPF 窗口布局、C# 玩法、Razor 页面结构 | 源码目录 | 构建并重启软件 |

这是带可编辑资源的自包含发布目录。C# 与 WPF 的程序逻辑仍编译在 DLL 中。
修改静态文件不会自动改变这些逻辑，也不要把安装目录里的 DLL 当成文本编辑。
剧本和存档仍在用户数据目录，发布文件夹不包含真实剧本正文或密钥。

二维码跟随所选局域网地址；如果电脑有多个网卡，可在面板里选另一个地址。
点「关闭平板连接」会停止网页服务，电脑端主持不受影响。
换剧本会停止旧服务并清除旧角色认领状态；新剧本需要在设置中重新开启连接。
没有真实剧本（演示局）时会提示先打开真实剧本，不会用演示材料冒充。
