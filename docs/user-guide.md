# 使用说明（0.1）

面向使用的 Windows 用户：单电脑、公共屏幕、4–6 名真人一局。

## 安装与启动

两种任选：

- **安装包**：双击 `LocalDm-Setup-x64.exe`，按向导完成（per-user，无需管理员）。桌面/开始菜单会出现「本局主持」。
- **便携包**：解压 `LocalDm-win-x64.zip` 到任意目录，双击 `LocalDm.exe`。

两种情况都**不需要**安装 .NET SDK 或 .NET 运行时（自包含发布）。

数据位置固定为 `%LOCALAPPDATA%\LocalDm`，**不在安装目录**；卸载不会删除它。

## 首次设置（设置与诊断页）

1. **模型地址**：默认 `http://127.0.0.1:3425/`。首版只接受本机 loopback 地址，填别的会被拒绝。
2. 点「读取模型列表」→ 选择实际 model ID（默认推荐 `codex/gpt-6.1-sol`，其次 `workbuddy-ai/deepseek-v4.1-flash`）。
   不要选 `group/auto…`、`auto/…` 这一族路由：它们不转发 system 消息，AI 主持会拿不到剧本资料。
   列表成功只说明端点可用，不代表生成一定成功。
3. **中文声音**：下拉框选音色，点「试听」。没有中文音色时应用仍会显示文字，只是不播音。
4. **caller key**（可选）：本机 Magpie 通常不需要。填了之后点「加密保存 caller key」，密钥用 Windows DPAPI 保存，
   普通设置文件和日志里不出现明文。
5. 点「保存设置」。

## 导入新剧本

剧本库里点「导入新剧本」，按五步走。**全程不显示剧本正文、卡面、真相或缩略图**：
只显示文件夹名、页数、进度和不含剧情的流程信息，所以导入的人即便是这局的玩家也不会被剧透。

1. **选文件夹**：选剧本所在的文件夹；剧本名默认取文件夹名，玩家人数填 4–6。
2. **确认分类**：软件按文件夹名与路径先猜出「组织者手册 / 角色本 / 线索卡」，每个分组一行，
   带页数、文件类型和猜测依据。猜错就在下拉里改。没有组织者手册时这里会要求指定一个，不能跳过；
   角色本分组数与玩家人数不一致也会提示（不阻止）。
3. **识别**：逐页识别图片或 PDF 里的文字，显示「第 N / 共 M 页」、预计剩余与失败页数，可以取消。
   取消或中途关掉软件都没关系：已经识别完的页存在本地缓存里，下次导入同一个文件夹会直接复用。
4. **确认流程**：AI 读过组织者手册后起草环节（标题、类别、提示、推进条件、依据页）。
   每一环都能改、能删、能上下移动；删掉唯一的揭示环节会被挡住。
   被判定为「可能含剧情」的提示只显示「已隐藏，请重写」，重写或删除之后才能继续——
   这类提示读着像剧情时请直接删掉。手册分层只显示页号与页数范围，可以按页切换
   「真相 / 主持人专用 / 不入包」，看不到那一页的内容。
5. **完成**：显示能不能开局；不能开局时只列问题类别与分组名。点「打开这一本」直接进主持台。

导入完成后这本会出现在剧本库里。以后想改流程，点这本书后面的「重新整理流程」，
回到第 4 步改完确认即可，不用重新识别；改流程会得到新版本的包，旧存档仍绑在旧包上。

## 主持一局

主持台右侧是「本局阶段」面板：

1. 点「装载演示剧本」（当前版本内置合成演示剧本；真实剧本需经准备流程，见下）。
2. 勾选「大家已口头准备好」——**不勾选就无法开始**。
3. 点「开始这一局」。
4. 每推进一个环节：勾选准备 → 点「下一环节（已勾选准备）」。
5. 搜证阶段点「发放一个材料编号」，面板会显示已发放的编号（只显示编号，不显示内容）。
6. 投票：用纸笔收集后，在「纸笔汇总」框按 `A=3, B=2` 格式录入，勾选「确认这是大家核对过的汇总」，点「提交票数汇总」。
7. 揭秘：勾选「确认这是公开揭秘，且原本条件已满足」，点「揭秘」。解密内容之后才会出现在面板上。
8. 点「进入复盘」。

「暂停并保存」可随时保存；「继续（恢复）」会校对剧本指纹后回到上次已提交的状态，**不会自动重播**。

## 语音输入

- 点输入框右侧的麦克风（或按右 Alt，只在本软件窗口在最前面时有效）开始说话，界面显示「正在听…」；再点一次结束，最长 60 秒自动结束。
- 转出的文字填进输入框，**不会自动发送**，改好后再按 `回车` 或「发送」；`Shift+Enter` 换行；中文输入法组字过程中的回车不会误发。点麦克风时会先停掉当前朗读。
- 第一次使用要准备语音模型（约 0.9 GB，从 OpenLess 已下载的模型复制，一次性），界面会显示进度；找不到模型时会明说。
- 录音只在你点按钮之后进行，音频只放在内存里，本机识别，识别完即丢，不落盘、不上传。
- 也可以直接粘贴文字，或继续用 OpenLess（文字框拿焦点后按它的热键），两者不冲突。

## 公共口播与重播

- 「公共开场」会请求本机模型生成一句主持词并朗读。
- 「停止」取消当前请求与播音；取消之后才到的回复既不会显示也不会播。
- 「重播」只播已保存的公开文字，不重新请求模型、不改游戏状态。
- 同一时刻最多一段播音。

## 私人材料

角色秘密与角色本**不会进入主持模型和公共屏幕**。请使用纸本或软件外的独立 PDF，也可以让玩家用平板按认领的角色看自己的角色本（见下一节「平板」）。
公共屏幕、TTS、日志与普通问答始终只能拿到当前已公开的内容。

## 平板

同一个 Wi-Fi 下的 iPad 或安卓平板，用浏览器扫剧本库页的二维码（或输入网址）就能加入，认领一个角色后看自己的角色本、全部线索卡和公共对话。

- 平板底部有一条输入条：认领角色后可以发言，发出去的话在电脑对话里显示为「【角色名】……」，全桌可见，和电脑输入框走同一个入口。
- 主持正在回答或朗读时所有平板的发送键灰掉，显示「主持正在回应」，不排队、不打断；单条最多 300 字，同一平板两次发送至少隔 2 秒。
- 平板上说「进入下一环节」「揭秘」只会在电脑上出现一条提议提示，不会推进；推进、揭秘、录入投票、压缩上下文都只能在电脑上做。「压缩上下文」在平板上当普通话处理。
- 平板只用系统键盘输入，想语音请用键盘自带的语音输入；平板不录音，也不会出声，主持的回答仍由电脑音箱朗读。
- 平板界面镜像（ADR 0008，开发中）：平板上会出现和软件一致的界面，显示当前环节、环节列表和公开对话；开始、推进、放出材料、提交投票、揭秘、结束、暂停/继续显示成灰色并写「请在电脑上操作」，竖屏放不下时折叠成一行当前环节。备忘、上下文占用等内部状态不显示。电脑屏幕不会被推送到平板。
- 状态：自动测试已覆盖并发与规则；真实 iPad 和安卓平板的实机验证还没做，做完前不要当作已验收。

## 纸笔投票的前提

本软件不提供单屏电子秘密投票。开局前必须明确接受「纸笔收集 + 主持人录入」这种方式，并且剧本原本允许；
否则不支持该局。

## 恢复一局

关掉软件再打开，点「继续（恢复）」：
- 会检查剧本包指纹；如果剧本文件被改动过，会拒绝继续（`PACKAGE_MISMATCH`）；
- 只恢复最后一次完整提交的状态，未提交的操作不会补做；
- 恢复后不会自动播音。

## 故障时怎么办

| 现象 | 处理 |
|---|---|
| 无法连接本机 Magpie | 确认 Magpie 在运行；`/health` 返回 404 是正常的，用「读取模型列表」判断 |
| 没有声音 | 设置页确认中文音色；文字仍会显示，进度不受影响 |
| 麦克风没反应或提示没听清 | 检查 Windows 设置 → 隐私 → 麦克风是否允许桌面应用使用；也可以直接手动打字或粘贴，功能不受影响 |
| 误点重复操作 | 同一操作重复提交只会生效一次 |
| 剧本文件被改动 | 恢复会被拒绝，需要重新准备剧本包 |

## 当前版本的限制

- 内置只有**演示用合成剧本**；真实剧本需要准备流程（当前本机 MinerU 缺少解析引擎，受阻，见 `docs/evidence/us2/`）。
- 未做代码签名，首次运行可能出现 SmartScreen 提示。
- 首版只支持 4/5/6 人，单电脑，无账户、无房间；平板只是同一局域网里的浏览器会话（见「平板」一节）。
