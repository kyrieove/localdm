# 平板 App（Flutter）可点原型 ·「灯下」

日期 2026-10-25。状态：**原型，待用户在真机上试**。本文件取代 `2026-10-25-tablet-flutter-app-design.md` 里的三个视觉方向。用户原话：「原因就是他们看起来像网页 而不是平板app；风格作废 你自己设计」。

不含剧本正文、卡面或真相：原型的文字全部来自合成剧本《雨停之前》（`SpikeTabletContent`）。

## 1. 怎么看

- 代码：`apps/tablet/`（Flutter 3.47.8，`--platforms=android,ios,web`，不进 `LocalDm.slnx`）。
- 截图：`docs/preview/tablet-app-flutter-20261025/shots/`，19 张，iPad Air 4 横 1180×820、竖 820×1180，安卓 1280×800。
- 本机运行（Flutter 装在 `.tools\flutter`，pub 缓存在 `.tools\pub-cache`）：

```
cd apps/tablet
flutter build web --release --no-web-resources-cdn
python -m http.server 8790 -d build/web      # 或用 .claude/launch.json 的 tablet-prototype
```

打开 `http://localhost:8790`，浏览器窗口调成 1180×820 或 820×1180。右上角烧瓶按钮是**原型调试抽屉**（真 App 没有），用来切换各种状态。网址参数可直达某一屏：

| 参数 | 值 |
|---|---|
| `stage` | `connect` `localNetwork` `waitingStory` `preparing` `pickRole` `inGame` |
| `section` | `book` `cards` `talk` `handbook` |
| `page` / `text=1` / `immersive=1` | 原稿页码 / 文字版 / 收起控件 |
| `night` | `off` `dim` `invert` |
| `theme` | `dark` `light` `system` |
| `sheet` | `phase` `reading` `role` |
| `offline=1` `speaking=1` `unread=N` `clean=1` | 断线 / 主持人在说 / 对话未读数 / 隐藏调试按钮 |

截图脚本：`bash apps/tablet/tool/shots.sh <输出目录>`（本机 Chrome 无头模式）。

## 2. 为什么这版不像网页（逐条可查）

| 网页的样子（上一版） | 这版 |
|---|---|
| 顶部一排文字页签 | 左侧 `NavigationRail`（宽 ≥600，iPad 横竖屏都是）；分屏窄于 600 换底部 `NavigationBar` |
| 阅读页四周都是界面 | 原稿全屏；轻点中间才出控件，**一翻页控件和导航栏一起收起** |
| 页面里插一行提示字 | 提示用底部面板（`showModalBottomSheet`）、`SnackBar`、系统样式对话框 |
| 整页跳转 | 平台转场：iOS `CupertinoPageTransitionsBuilder`（右滑返回），安卓预测返回；各步之间淡入淡出 |
| 悬停态、滚动条、「复制地址」 | 没有。连接靠相机扫码，手输地址是后备 |
| 翻卡靠点按钮 | 长按卡片 3D 翻面 + 震动（`HapticFeedback`），按钮是后备 |
| 横屏只是把网页拉宽 | 横屏原稿**双页并排**；线索卡变成左墙右详情（Material 3 list-detail） |
| 断线就白屏 | 顶部滑下横幅，已打开过的页继续能看，自己重连 |

## 3. 风格「灯下」

围桌的房间常常很暗，平板是玩家手里的一盏灯。默认深色：近黑的暖灰底 `#14120F`，唯一强调色是台灯的琥珀 `#F2B35E`，其余全是灰阶。浅色是白天用的同一套色相。字体用系统字体（iPad 苹方、安卓 Noto），App 不带字体文件。

原稿扫描页是白纸，暗房间里刺眼，所以给原稿单独的夜读：

| 档位 | 做法 | 纸与字对比度 |
|---|---|---|
| 原样 | 不处理 | 11.99 |
| 压暗（默认） | 整体降亮、偏暖 | 5.53 |
| 反白 | 纸变暖近黑、字变暖米色 | 9.05 |

数值由 `test/contrast_test.dart` 用界面同一份颜色矩阵算出，纸色和字色取自占位页。**真实扫描页要抽样复核**（纸可能发灰，压暗档最先不够）。

界面文字对比度（同一测试，全部 ≥4.5:1）：深色正文 14.93、次要字 6.78–8.32、琥珀强调字 8.26–10.14、按钮字 8.96；浅色正文 16.02、次要字 6.24–7.45、强调字 5.87–7.00、按钮字 7.48。

## 4. 每一屏

| 屏 | 组件 | 要点 |
|---|---|---|
| 扫码连接 | 自画取景框 + 扫描线动画；真 App 用 `mobile_scanner` | 横屏左取景右说明，竖屏上下；「扫不了？手动输入地址」弹对话框 |
| 本地网络授权（仅 iPad） | 说明页 → `CupertinoAlertDialog`（原型模拟系统框） | 先讲为什么要点「好」；点了「不允许」给出设置路径 |
| 等剧本 / 准备中 | 呼吸的灯 + `LinearProgressIndicator` | 左上角显示「已连上 IP」，不用玩家做任何事 |
| 选角色 | `GridView` 角色牌，名字最后一个字当头像 | 已认领换底色加锁，不用半透明；点牌从底部确认；被抢先（409）震动 + `SnackBar`，牌变成已认领 |
| 角色本·原稿 | `PageView` + `InteractiveViewer` | 竖屏单页、横屏双页；左右各 18% 宽轻点翻页；中间轻点开关控件；双击放大 2.5 倍到点击处，双指最大 4 倍；放大时禁止翻页只平移 |
| 角色本·文字 | `ListView`，行宽 ≤34 字 | 字号 16–28、行距三档；**长按一段跳到它所在的原稿页** |
| 线索卡 | `CustomScrollView` 按分组；≥840 宽左墙右详情 | 竖屏点卡用 `Hero` 飞到全屏黑底，可缩放，下拉关闭；整组暂停分发时组名旁标出 |
| 公开对话 | 倒序 `ListView`，最新贴底 | 主持人说话时标题旁三根竖条跳动；底部写「想问主持人，到电脑前按住说话」（平板不能发言） |
| 环节 | 导航栏顶部的环形表盘「2/4 搜证」 | 点开底部面板：环节列表、提示、已发/待发材料数、「推进环节请在电脑上操作」 |
| 我的角色 | 导航栏底部琥珀头像 | 底部面板：退出角色（二次确认） |
| 遮住屏幕 | 导航栏底部的眼睛按钮 | 全黑遮罩，轻点两下回来 |

## 5. 手势与动效参数

| 动作 | 触发 | 时长 / 曲线 | 跟手 |
|---|---|---|---|
| 翻页（滑动） | 横向拖动 | 系统 `PageScrollPhysics` | 是 |
| 翻页（轻点） | 左右 18% 区域 | 260ms easeOutCubic | 否 |
| 到第一页/最后一页还翻 | 同上 | 轻震 `lightImpact`，不弹提示 | — |
| 控件显隐 | 中间轻点；翻页自动收起；拖页码滑条时不收 | 淡入淡出 180ms；导航栏宽度 240ms | 否 |
| 双击放大 / 还原 | 双击 | 220ms easeOutCubic，2.5 倍 | 否 |
| 双指缩放 | 捏合 | 1–4 倍 | 是 |
| 卡片翻面 | 长按卡片或按钮 | 360ms easeInOutCubic，绕 Y 轴 + 透视；`mediumImpact` | 否 |
| 全屏看卡关闭 | 下拉 >120pt 或速度 >900pt/s | 背景随拖动变淡 | 是 |
| 切换导航页 | 点导航栏 | 220ms 淡入淡出 | 否 |
| 各步之间 | 自动 | 280ms 淡入淡出 | 否 |

## 6. App 独有状态

| 状态 | 玩家看到 | 原型里怎么看 |
|---|---|---|
| 第一次打开 | 扫码页 | `stage=connect` |
| iPad 本地网络授权 | 说明页 → 系统框；拒绝后给设置路径 | `stage=localNetwork` |
| 已连上，主持人没开剧本 | 等待页 | `stage=waitingStory` |
| 材料准备中 | 等待页 + 进度条 | `stage=preparing` |
| 认领被抢先（409 `TAKEN`） | 震动 + 提示，牌锁上 | 调试抽屉开「下一次认领被别人抢先」 |
| 断线 | 顶部横幅；缓存外的页显示「连上电脑后自动出现」 | `offline=1` |
| 杀掉 App 再开 | 直接回到阅读页 + 「已回到第 N 页」 | 调试抽屉「杀掉 App 再打开」 |
| 暂停分发的卡组 | 组名旁「这组暂停分发」，卡不能点 | 调试抽屉开「回忆组暂停分发」 |

## 7. 缓存与内存

- 只在内存里留当前页前后各 2 页（`precacheImage`），共 5 页。断线时只有这 5 页还能看（`test/behavior_test.dart` 断线用例）。
- 解码宽度上限 1100px（`ResizeImage`）：iPad Air 4 竖屏整页显示约 535pt 宽 ×2 ≈ 1070px。真实扫描页 1754×2480 不压要约 17MB/页，压到 1100 宽约 7MB/页，5 页约 35MB。
- 卡片打开时先解码背面，翻到一半背面已就绪。（浏览器里实测：不预解码时第一次翻面会闪一帧空白。）

## 8. 接口缺口（做真 App 前要补）

原型的假数据就是合成服务的真实返回（`apps/tablet/assets/fixtures/*.json`，用 `ASPNETCORE_ENVIRONMENT=Development` 起 `src/LocalDm.Tablet` 录的）。对着它做界面时发现四处 HTTP 接口拿不到、只有 Blazor 页面在进程内能拿到的信息：

1. **角色本原稿页数**：`/tablet/role/book` 没有这个字段，只能逐页请求直到 404。原型写死 12。
2. **手册页数**：同上，原型写死 4。
3. **剧本状态**（没开剧本 / 准备中 / 可选角色）：Blazor 直接读 `TabletStoryState`，HTTP 没有。等待页要靠它自动往下走。
4. **卡片有没有背面**：`/tablet/catalog` 的卡片没有这个字段，只能请求背面看是不是 404。

另：枚举在 JSON 里是字符串（`"status": "Current"`、`"kind": "Paragraph"`），契约测试要把这一点钉住。

## 9. 测试

`cd apps/tablet && flutter test`，9 项全过：

- 对比度：深色、浅色每对文字/底色 ≥4.5；原稿三档夜读 ≥4.5。
- 行为：iPad Air 4 横竖屏都是侧边导航、窄于 600 换底部导航；认领被抢先留在选角色页并提示；竖屏右侧轻点翻一页且控件收起；横屏翻页跳两页；卡片翻面、无背面的卡提示；断线后只有前后两页可看。

测试环境的字体是方块，外观只靠截图看。

## 10. 没验证的

- **没上过真机**：双指缩放手感、翻页帧率、震动、常亮、沉浸全屏、相机扫码、iOS 本地网络弹框，都只在浏览器或代码里，没在 iPad Air 4 或安卓平板上跑过。
- 浏览器里的 Flutter 网页版用的是 CanvasKit 和网络字体，帧率和字形与真机不同。
- 真机验收方法沿用旧设计文件 §7、§8：真机 profile 模式翻 20 页，超过 16ms 的帧 ≤1%；2–3 个朋友不经提示完成认领、读到第 3 页、翻开一张线索卡。
- 最快的真机路径是安卓 apk：要把 Android SDK 和 JDK 装进 `.tools\`（几 GB），这一步等用户决定。iPad 要走 GitHub Actions 出未签名 ipa 再用 iloader 装。
