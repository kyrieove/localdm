桌面主持与平板已接入同一进程。选定真实剧本后，在偏好设置中开启平板连接，即可获得本局网址和二维码。

## 立即测试
```callout ok 从软件进入本局网页
双击仓库根目录的「启动本局测试.cmd」。
启动器直接打开已编译的 EXE，不再另开 demo 服务。
从剧本库选择真实剧本后，在「偏好设置 → 平板连接」点「开启平板连接」。
```
二维码和网址显示在同一个设置页，可用按钮关闭连接。没有平板清单的包会提示准备材料，不会退回演示剧本。

## 两条测试路径
```flow LR
启动器 -> 桌面窗口: AI 主持与本局存档
```
