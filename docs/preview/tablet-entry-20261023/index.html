连不上怎么办
  1. 平板和电脑连同一个 Wi-Fi。
  2. Windows 第一次弹出网络提示时，选「专用网络」并允许。
  3. 网络类型若是「公用」，在 Windows 网络设置里改成「专用」。
  4. 仍不行：点上面的网址在电脑浏览器里试一次，能开说明是平板那边的网络。

局本局主持 · 平板
① 服务常驻软件一打开就有二维码和网址，网址固定，平板收藏一次就能一直用。
② 放原件，不放重排文字角色本是导入的 PDF 页或图片原样，线索卡是卡面/卡背原图。
③ 平板自动跟随电脑打开、更换剧本时，平板不刷新、不重扫，自己切换；换剧本会清空角色认领。
④ 只显示剧本名版本号不出现在任何界面上；同一本剧本只有一行。
⑤ 出错直说原因端口被占、被防火墙拦，都写在二维码卡片上，并给出一步到位的做法。
