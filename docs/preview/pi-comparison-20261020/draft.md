## A 先看结论 {span=2}
```callout info 更值得验证的是“先查证，再回答”
现在，程序先准备资料，模型据此回答。
接入专用工具后，Pi 可以组织模型按需查询，再回答。
它不会自动提升模型能力，也不会自动解决剧本准备。
```

接入 Pi 是待验证的设计，目前项目没有这条链路。
比较使用同一个模型，避免把换模型的收益算给 Pi。

## B 玩家实际会感觉到什么 {span=2}
| 对比点 | 当前已实现 | 拟接入 Pi 的 DM |
| --- | --- | --- |
| 普通提问 | 当前公开上下文加玩家提问，生成回复 | 简单问题可直接答，不必每次查工具 |
| 复杂问题 | 主要依靠程序预先选好的上下文 | 可先查规则或已公开材料，再组织回答 |
| 连续追问 | 界面有历史，但当前问答请求只构造两条消息 | 可管理本局历史；隔离、摘要和恢复仍需接入 |
| 当前进度 | 游戏程序记录并决定 | 仍由游戏程序记录；agent 通过工具查询 |
| 推进和揭秘 | 点击按钮，规则核心检查后执行 | agent 可提出建议，点击后仍经规则核心 |
| 剧本适配 | 准备流程声明，界面按剧本包显示 | 可辅助整理声明；来源核对与就绪检查仍保留 |
| 防剧透 | 在公开投影和提示词构造处过滤 | 每个查询工具也必须过滤，不能读取全本 |
| 等待和费用 | 正常问答走一次模型生成 | 需要查证时可能有更多模型轮次和工具调用 |
| 维护工作 | 当前 C# 应用、网关与语音链路 | 增加 Pi 运行进程、工具接口和故障处理 |

这里没有速度、费用或正确率的实测对比。
收益是设计预期，必须通过相同问题的对照验证。

## C 当前：程序把资料递给模型
```flow TB
玩家提问 -> 程序选取当前公开内容
程序选取当前公开内容 -> 模型生成回复
模型生成回复 -> 显示文字并按设置朗读
```

当前输入包括环节、提示、条件和允许公开的原文。
材料部分给出已公开编号，不是任意线索全文检索。
这个流程已经能完成基本主持，结构也更简单。

## D 接入后：允许先查询，再回答
```flow TB
玩家提问 -> DM 判断需要哪些依据
DM 判断需要哪些依据 -> 查询受限的 DM 工具: 需要查证
查询受限的 DM 工具 -> DM 根据查询结果继续判断
DM 根据查询结果继续判断 -> 生成有依据的回复
DM 判断需要哪些依据 -> 生成有依据的回复: 无需查询
生成有依据的回复 -> 显示文字并按设置朗读
```

拟提供的工具包括查进度、查公开规则、检索已公开材料。
Pi 负责组织这串动作，模型负责理解和回答。
工具内容、访问权限和正确结果，需要本项目实现。

## E 用同一个问题看区别 {span=2}
> 玩家：刚才那张线索，和你前面说的规则是不是矛盾？

| 当前做法 | 拟接入后的做法 |
| --- | --- |
| 把这句话和当前公开上下文交给模型 | 先判断“刚才那张”是否能从本局历史定位 |
| 上下文不包含对应原文时，回答依据不足 | 无法定位就追问编号，不猜是哪张线索 |
| 当前链路没有模型主动检索材料的工具 | 查询该编号是否已发放，再取允许公开的原文 |
| 可以请求玩家补充上下文 | 查规则出处，对照后回答，并指出不确定之处 |

这是预期工作过程，不是已经完成的效果测试。
查询只返回当前允许公开的内容，不外发角色秘密。

## F 怎么接，哪些事仍然不变 {span=2}
```flow LR
WPF 对话界面 -> Pi 独立进程: 发起一轮互动
Pi 独立进程 -> 受限 DM 工具: 按需查询
受限 DM 工具 -> 现有公开投影与存档: 核验权限与状态
```

准备期可以读取完整剧本，现场公共 DM 使用独立上下文。
现场 agent 不开放通用读写文件和终端工具。
游戏进度仍以现有存档为准，不能以聊天记忆代替。
玩家未主动提问时，仍不持续监听或主动催促。

Pi 的官方 SDK 支持自定义工具与会话管理。
官方 RPC 支持通过独立进程与其他语言通信。
现有 Magpie 调用只使用文字消息，未传工具定义。
因此，还要验证或调整模型接入，不能直接假定兼容。

## G 先做一个可比较的小验证 {span=2}
| 检查 | 看什么结果 |
| --- | --- |
| 同模型、同剧本、同问题 | 单独比较查询与上下文组织带来的变化 |
| 规则追问、线索关联、模糊指代 | 是否找对依据，是否在需要时追问 |
| 诱导剧透、越权查询 | 未公开内容是否始终无法取得 |
| 等待、调用数、使用量 | 回答质量提升是否值得额外开销 |

建议先稳定流程、存档和语音，再验证只读 DM 工具。
不必先更换界面，也不必把所有操作交给 agent。
