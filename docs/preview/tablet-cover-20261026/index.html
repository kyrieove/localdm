盖着的原稿页 · 三个方向

每个方向左边是「下一页」，按住约 0.65 秒翻开（松手或滑动作废）；右边是「更后面的页」，点一下会抖，提示先翻前一页。

A封条

像没拆封的角色本：一道封条斜贴在页中间，上面印页码。按住时灯色从左往右把封条「烧」开。仪式感最强。
