# 平板网页界面：三个方向（预览稿，未改任何 razor）

日期 2026-10-23。用 huashu-design 技能做的三方向门。三版用同一份界面清单和示意数据，只换骨架与外观。示意数据和示意正文全部自编，不来自任何剧本；没有读 `stories/`、`.appdata/`、`.local/`。

预览怎么看：直接双击打开 `dir-1.html`、`dir-2.html`、`dir-3.html`。顶部控制条切状态（等待、材料准备中、加入页、认领失败、原稿、文字重排、字号设置、线索卡、公共对话三个环节、阅读时开对话）、切尺寸（横屏 1180×820、竖屏 820×1180、安卓竖屏 800×1280）、模拟「主持正在回应 / 朗读中 / 发送出错」。发送框能真的输入，发出去会进对话列表。

## 共同遵守的约束
- 公开消息只有 `Kind` 和 `Text`，没有发言人、时间；角色只有名字和是否已认领。方向三的角色识别色按名单顺序取色，不需要新字段。
- 灰色按钮不可点（ADR 0008），能点的只有发送和停止朗读；不显示备忘、上下文占用。
- 角色本默认原稿页，界面不出现版本号。
- 只用系统字体，衬线回退 `Songti SC / Noto Serif CJK SC / SimSun`；触控目标 ≥44px，正文 ≥16px。

## 方向一「书卷」：保留现有纸色朱砂，做成一本书
- 来源：书籍装帧思维（吕敬人一路）。只借思路，没有核实具体作品，也没有截参考板。
- 借的：版心、页眉、书脊、印章。
- 主角素材：朱砂「印章」角色名牌＋左侧书脊色带。
- 骨架：和现在一样的顶部页签＋单栏居中；公共对话横屏左目录右对话，竖屏折叠成一行当前环节。
- 胆量花在哪：角色名做成竖排印章，名牌是一张张「名牌」。
- form 来自内容：剧本杀的「卷宗」感，局面像翻一本案卷。
- 落地：只改 `reader.css` 和少量 `Home.razor` 类名，改动最小。需要动：`.join` 改两栏、`.role-list` 改成名牌格、`Home.razor` 顶栏把页签并进顶栏、`LiveBoard.razor` 目录改时间线样式。

## 方向二「暗室」：夜里围桌，屏幕不刺眼；横屏左边读右边看对话
- 来源：夜间阅读器的常见做法加「深底单点缀」外观家族（琥珀）；没有核实具体作品。
- 借的：夜间阅读深色底、原稿页压暗，减少夜里对着一圈人的眩光。
- 主角素材：压暗的原稿页，右侧常驻对话栏，琥珀一个点缀色。
- 骨架：横屏左导航栏＋阅读区＋右侧对话栏（读角色本、看线索卡时对话常驻，不用来回切页签）；竖屏导航沉到底部，对话是底部抽屉。
- 胆量花在哪：把公共对话从页签变成常驻侧栏，读的时候也能看到环节和最新发言。
- form 来自内容：围桌玩、灯光暗。
- 落地：要动 `Home.razor`（导航从顶部页签改成侧栏／底栏，工作区加右栏）、`SpeechBar.razor`（横屏时移进右栏，`ShowPanelToggle` 的意义变成竖屏抽屉）、`reader.css`（整套深色变量，要有 `prefers-color-scheme` 或手动开关，建议加一个「夜间」开关）。改动最大。

## 方向三「牌桌」：大按钮、环节条常驻、底部操作条
- 来源：游戏手柄式的大触控目标，加「冷灰底＋墨蓝＋信号橙」的现代 App 风格；没有核实具体作品。
- 借的：每个角色一个识别色，环节进度条一直挂在顶部，翻页键放在页面两侧边缘。
- 主角素材：六张大色块名牌、顶部环节进度条。
- 骨架：顶部深色环节条（所有页签都能看到当前环节）；底部一条操作条＝三个页签＋发言框＋发送，竖屏分两行。
- 胆量花在哪：加入页是六张整屏大色块；环节进度从公共对话页提升为全局常驻。
- form 来自内容：桌游的牌与名牌。
- 落地：要动 `Home.razor`（顶栏换成环节条，要把 `TabletUiProjection` 的环节提到外壳；页签与 `SpeechBar` 合成底部操作条）、`SpeechBar.razor`、`reader.css`。顶部环节条在没有开局（`Ui` 为空）时要有空态。
- 风险：色块名牌的识别色按名单顺序取，换剧本角色数不是 6 时要有色板回绕规则。

## 没做的、没验的
- 技能要求的「六候选缩略图」一步省掉了：直接做了三个完整版，备选没有出。
- `design_lint.py check` 体检因本机没装 Python 版 playwright 跳过，用 Playwright MCP 在横屏 1180×820、竖屏 820×1180 肉眼看过；安卓竖屏 800×1280 只靠尺寸切换，没逐屏看。
- 没在真实 iPad 和安卓平板上验过；字体在平板上的实际回退没验。
- 外观账（`design_lint.py ledger add`）和 `direction-approved.md` 等用户选定后再写。
