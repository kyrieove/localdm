    这次界面重塑，保留什么、移走什么

    审查范围为当前桌面端的主窗口、主持台、设置页、剧本库及命令条件。这里展示的是待讨论的界面方案；原程序没有被改动。

    从三栏控制台，改为一条对话主线

    左侧负责「现在到哪、还差什么、我能做什么」。主区负责「玩家说了什么、主持人怎么回答」。移除固定右栏、重复环节大标题和常驻“就绪”面板，给长回复与公开复盘留出宽度。仍沿用米白纸面、墨色文字和少量印章红。

    当前功能预期处理原因与边界
    本环节、阶段进度、原本条件合并到左侧不再在顶部、中间、右边重复显示。条件仍可见，避免误推进。
    大家已准备好 / 下一环节删除勾选，动作名称随剧本变化例如「进入第二轮搜证」。点击即表示准备推进；机器可检查的条件仍校验。
    开始这一局仅待开局时出现进入游戏后由剧本定义的下一步动作取代，不保留一块永久禁用的按钮。
    发放材料编号仅有待发材料时出现左侧逐个发放；公开编号作为事件进入对话，完整编号列表在主区查看。
    投票输入 / 提交票数投票环节才显示入口检查总票数，点击「确认提交汇总」即确认，不再额外打勾。
    揭秘 / 进入复盘按阶段显示明确标为「公开真相」，说明将向全体公开。点击即确认，不再打勾或重复弹窗。
    暂停并保存 / 继续左侧一个切换按钮取消两个互相排斥的常驻按钮。暂停后明确显示存档状态。
    公共开场改为按阶段的「请主持人开场」仅开场场景提供快捷意图，避免在每个环节都重复“开场”。
    停止 / 重播跟随播放状态与消息生成或朗读时在输入区停止；每条已生成回复旁可重播，不重新请求模型。
    主持记录 / 实时互动合并为连续对话按时间顺序区分玩家、AI 和阶段事件，取消两个互相割裂的区域。
    固定“就绪”状态条移除整块占位仅在实际生成、朗读、失败时就地反馈，不把“空闲”误写成“设备就绪”。
    装载演示剧本移到剧本库正式游戏过程中不摆放切换到演示的入口。
    音色 / 试听 / 重新检测左下角进入声音设置音色不占对话顶部；检测放到设置，常用信息保持可达。
    caller key 输入与加密保存移除日常可见控件本机通常不需要。隐藏展示不等于删除网关鉴权和现有密钥存储能力。
    模型地址 / model ID / 读取列表收进设置日常只显示连接状态和易读名称；地址与连接检测放高级设置。
    MinerU 路径 / 文档工具说明移出游玩界面文档工具属于准备流程；游玩读取准备好的剧本包，不要求玩家配置解析工具。
    revision、回执与工具细节退出公共显示保留内部存档与诊断，玩家只看到清楚的动作结果。

    这个原型可以试什么

    发送示例消息、生成中停止、重播状态、直接点击下一步、切换不同剧本流程、逐个发放材料、投票校验、点击公开真相、暂停与继续、剧本库和设置。顶部可切换「单轮 · 有投票」和「双轮 · 无投票」，再选任意步骤查看对应动作。这两套均为界面演示数据，不是自动解析真实剧本的结果。

    原型与实际功能的界限

    对话、剧本条目、材料编号和状态反馈都是浏览器内的演示数据，不调用模型、语音或存档。没有新增录音按钮、账户、多人房间或自动推进。音频设备检测/选择也未冒充现有能力。
