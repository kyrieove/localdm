# 语音输入引擎实测（2026-10-23）

命令：`dotnet run --project tools/LocalDm.Probe -- --dictation-check`

做法：用 Windows 中文语音合成朗读固定句子，16 kHz 单声道 16 位，交给本机 Qwen3-ASR（sherpa-onnx 1.13.8，CPU，4 线程）识别。

| 项目 | 结果 |
|---|---|
| 识别结果 | 与朗读句子逐字一致（含标点） |
| 模型加载 | 5380 ms |
| 识别 | 815 ms |

**这次实测证明什么**：模型能在本机 C# 里加载并识别，速度可用。

**这次实测没证明什么**：
- 用的是合成语音，不是真人嘴说话；真实口音、噪声、断句下的准确率没测。
- 没经过麦克风录音这条路径（NAudio），也没点过界面上的麦克风按钮。
- 只测了一句。

待做：用启动器 `启动本局测试.cmd` 在主持台实机点麦克风说几句，把结果补在这里。首次使用要先复制约 0.9 GB 的模型，需要等一会儿。
