## 本轮已完成的替代验证（不等价）

这些证明**流程正确**，但**不能**证明：
- 真实剧本的页块来源与语义保真；
- 真人局中的实际操作节奏与无剧透体验；
- 真实剧本下「没有必须由玩家阅读真相的步骤」。

## 执行这一项需要什么

1. 在应用专属 MinerU profile 中配置本地解析引擎（或提供 `formatVersion=1` 完整包）；
2. 用 `stories/` 下的真实剧本准备为 Ready 包，并由独立校验者逐项核对；
3. 组织 4–6 名真人，打印/分发软件外的角色本与线索卡；
4. 从准备玩到复盘，记录：页/角色/阶段/线索/真相来源核对结果、实际耗时、遇到的问题；
5. 把脱敏结果写入本文件，替换「未执行」结论。
