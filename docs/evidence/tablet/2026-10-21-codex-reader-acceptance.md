# Codex 独立验收：文字阅读探针

日期：2026-10-21。基线 `d8617b8` 已与 origin/main 同步；本轮接手其后的未提交阅读器工作。用户明确确认 DeepSeek 已停止写入，并授权 Codex 验收、修复、提交和推送。

## 结论与边界

本轮验收对象是**合成材料的文字阅读探针**，不表示完整平板第一期交付。它可以在本机网页认领独立角色、阅读文库纸页、按名称查看单张合成卡、查看固定合成公共对话。角色本、插图源页均为合成材料，未读取、打印或提交受保护的真实资料。

尚未完成：真实冻结剧本包和导入结果接入、可靠切图与真实卡片配对、WPF 进程内服务及开关、正式二维码/加入令牌入口、真实公共对话与当前环节同步、跨进程阅读进度持久化、真实 iPad 与安卓平板验收、发布物整体验收。当前服务独立运行，默认 127.0.0.1；不能说玩家已经可以拿真实剧本正式开局。

二维码和网址都保留为产品方向。现有 Python 二维码脚本仅为辅助探针，本轮没有将其自校验算作独立扫码通过，也没有将 Python 作为正式发布依赖。

## 本轮发现和修复

1. 参数更新时重复分页并回调父组件，造成重复渲染；改为有变化才在 DOM 更新后分页，进度未变不重复上报。首页在交互准备好后才显示按钮，避免预渲染按钮第一次点击无响应。
2. 页起点读取不存在的 fragment.offset，进度始终为 0；改为包含段内位置的 UTF-16 偏移，保留补充字符完整性，0 为有效位置。
3. 固定测量高度与自己比较导致 fits 恒失败；改为将完整页候选放进同尺寸测量区，按真实内容高度分页。长段能跨页，超大插图通过可滚动区域完整可达，不偷偷截掉。
4. 字号、行距与专注状态只改组件字段，不保存也不正确重排；现在保存当前设置，重新分页并恢复所在文本范围。章节导航、切页和横竖屏使用同一字符流。
5. 原稿只给单张固定图片；合成探针增加按本人角色与源页号取图，未认领、他人或越界请求拿不到原稿。响应 no-store，避免换角色后复用旧缓存。原稿与正文的真实内容对应仍须真实包接入后验证。
6. 换角色沿用旧阅读位置、复制按钮只显示成功、RoleName 显示成字面字符串，以及重复注册/运行服务等问题已修正。阅读页颜色直接使用现有 Shared.xaml 的纸色、墨色、分隔线与印章色，不依赖外部字体 CDN。
7. 测试并行发布共用 Release obj/bin，曾导致一次核心测试失败；只串行发布步骤，保留独立运行实例，并补 stdout、stderr、退出码和有效超时。没有删除测试或新增跳过。
8. 旧 PowerShell 辅助脚本点击失败仍输出 DONE；替换为调用带断言的 Node/Playwright 验收，错误必须非零退出，不自动 npx 下载依赖。

可重跑入口，需先启动一份新的合成探针，且事先安装可用的 Playwright 和 Chrome：

```powershell
dotnet publish src/LocalDm.Tablet/LocalDm.Tablet.csproj -c Release -o <临时发布目录>
# 在该目录运行，避免缺少 wwwroot：
dotnet LocalDm.Tablet.dll --urls http://127.0.0.1:5099/
# 在仓库另一个终端运行，模块目录由本机实际安装位置填写：
node tools/tablet-qr/verify-reader.mjs --url http://127.0.0.1:5099/ --playwright-module <playwright模块目录>
```

脚本仅允许本机地址，输出到合成验收目录，失败非零退出，结束时释放本次认领的角色并关闭浏览器。不自动安装运行时或下载浏览器。
