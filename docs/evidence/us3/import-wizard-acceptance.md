## 这次验收发现并修掉的两处问题

1. **中文类别解析**：提示词全是中文，模型常直接答「阅本」「搜证」「揭秘」，原来按枚举名解析会判成
   JSON 解析失败。现在中英文都认，认不出的类别仍判不合格（不猜）。
2. **起草失败时状态栏被覆盖**：`ExtractAndDraftAsync` 在起草失败后仍显示「流程由 AI 起草，请逐条确认」，
   掩盖了真实原因。现在失败时状态栏保留「AI 没能起草流程：<原因> 请自行填写环节」。
