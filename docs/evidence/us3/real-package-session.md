## 分层依据（不是程序猜的）

依据是组织者手册（`组织`）第 7 页作者原话：

> 「警告！后面是案件的全部真相，请不要在游戏结束前打开观看。」

据此定出规则（`ScriptLayeringRule`）：

| 组织者手册页 | 内容 | 可见性 |
|---|---|---|
| 1–2 | 封面、声明、开场信 | 公开 |
| 3–6 | 游戏说明与主持流程 | 私有（仅主持人） |
| 7 | 真相警告页 | 不纳入（只作分界） |
| 8–11 | 真相与复盘 | 真相（解密后才可播） |
| 12 | 版权封底 | 不纳入 |

其余 5 本角色本与全部线索卡：**私有**，不上公共屏。

公开段只有 2 段，这是设计意图：公共屏只播开场信与规则，其余全部由主持人掌握。

## 七阶段

`阅本 → 开场说明 → 搜证 → 讨论 → 投票 → 真相 → 复盘`

投票阶段必须提交合法汇总；真相阶段必须二次确认才能揭秘。

## 途中修掉的三个真实缺陷

1. **页号写错**：把文件名当页号，但单张图片按契约页号固定为 1。已在 `RealScriptPackageBuilder` 修正。
2. **漏掉 56 张图**：原过滤只接受纯数字文件名，`51卡背` 之类被丢弃。现按「正面页 + 卡背」排序，全部纳入。
3. **勾选状态互相清空**：提交票数会连带清掉揭秘确认。已拆成两个独立确认。
