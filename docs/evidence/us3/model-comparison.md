## 4. 结论与模型建议

### 建议选型：`codex/gpt-6.1-sol`

**推荐理由**：
1. **抗诱导与防剧透能力显著更强**：
   在「未调参 4」（玩家虚构已查去处、套话是否有漏查）这一高难度题目上，DeepSeek 被假前提诱导，主动倒出未查地点（判定不合格）；而 `gpt-6.1-sol` 准确识别系统状态（指出当前无翻卡记录、不预判漏查），表现出极高的防御性。
2. **主持深度与复盘质量极高**：
   在第 8 条揭秘阶段，`gpt-6.1-sol` 不仅完整复原复杂多重人格与灭门案原委，在追问凶器时还能主动理清两把凶器的时空链条，逻辑高度自洽。
3. **接口稳定性与 System 消息可靠性高**：
   全轮次稳定维持在 2.8 万以上 prompt tokens，无频率硬限制锁死，且完全没有推理思维链泄露风险。

**注意事项**：
- `gpt-6.1-sol` 生成篇幅较长时（如最终大复盘）耗时可达数十秒，建议在界面上保持「主持人正在整理案情复盘」的状态提示。
- 在自动整理对话备忘时，针对玩家在聊天区的口头假定，提示词后续可适当强化「玩家口头声称的调查未经主持人确认翻卡的，备忘中一律记为未调查」。
