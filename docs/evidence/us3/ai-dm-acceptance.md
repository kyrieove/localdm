**第 11 条判断的一次误伤与修正**：门限最初定 5 个字，第二轮验收里模型生成的备忘被整份拦下。
原因是卡面「内容只能自己看，可以转述或编造」被切在两个来源块里，主持人原话「可以转述或编造」
与其中一段正好有五个字相同，这是拼接出来的重合，不是转述。门限提到 7 个字之后，
真实包上同一段对话连跑三次整理请求，命中都是 0 条；旧备忘仍能判出 4 条。

## 环境备注

用户设置里的 model ID 是 `group/auto-deepseek-v4-1-flash`。实测该路由（以及 `auto/…` 这一族）
**不转发 system 消息**：用 30 字的 system（「记住这个词：蓝鲸七号」）请求，返回的 `usage.prompt_tokens`
只有 61，模型回答「你还没有让我记住任何词」；换成真实剧本包时同样返回 `prompt_tokens=159`，
模型回答「无法得知剧本名字」。同一台服务上换 `workbuddy-ai/deepseek-v4.1-flash` 与
`deepseek/deepseek-flash` 都能正常收到 system（`prompt_tokens` 分别为 24、49，答对内容）。
因此本次验收在命令里用 `--model` 覆盖为 `workbuddy-ai/deepseek-v4.1-flash`，其余设置不变。
这一条只影响验收用哪个模型，不改软件里的默认设置。
