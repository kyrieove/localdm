# 0010 模型提议改正：电脑确认后退回环节或重新录入票数

日期 2026-10-23。

## 背景
投票提交后录错了改不了，推进点错了退不回去。用户要求不写死按钮，靠模型理解「点错了」。

## 决定
1. 规则核心新增 `RevertPhase`，只允许游戏中退回上一环节；第一个环节、暂停中、已揭秘或已结束都拒绝。退回不改变已发放材料和票数记录。
2. 同一轮重新提交票数时，原位替换该轮原记录，没有记录才追加。
3. 模型只能在回复末行写 `〔提议：回到上一环节〕` 或 `〔提议：重新录入票数〕`。软件移除这一行，不显示、不进记忆、不朗读，并在电脑上显示确认条。主持人点确认才执行；改票时重新打开录入框并预填当前票数。模型不得写游戏状态。
4. 系统提示词追加第 10 条，说明提议规则，前 9 条不改。

## 否掉的方案
- 左栏常驻「退回」「改票」按钮：用户不要写死。
- 模型直接执行改正：违反宪章原则 III「模型不得写游戏状态」。

## 后果
- 模型没听懂时，玩家要再说一次。
- 退回不收回已发的材料。
- 揭秘以后不能退回。
