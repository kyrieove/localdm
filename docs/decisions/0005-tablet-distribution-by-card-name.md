# 0005 局域网平板分发，线索卡按名称点选

日期 2026-10-21。状态：产品范围已由用户确认，方案已写，尚未实施或完成真实平板验证。

## 决定

电脑内嵌局域网页面服务，玩家用 iPad 或安卓浏览器扫码加入，认领角色后查看整本角色本。平板同步公共对话和当前环节；公共操作仍由电脑完成。纸质模式保留。（2026-10-23 起“只读”被 [ADR 0007](0007-tablet-live-chat.md) 改写：平板可以发言，推进、揭秘、投票仍只在电脑；平板界面镜像见 [ADR 0008](0008-tablet-ui-mirror.md)。）

用户最后明确：“不需要知道能不能翻 所有的卡按照名称列出来 玩家点击哪个推送哪个”。因此全部已准备好的线索卡名称从加入后可见，点击提供对应单卡，程序不根据环节判断开放，也不弹出剧本前提确认。名称提前整理，稳定卡片编号索引实际图片，不按模糊名称猜图。

卡片裁切和配对不可靠时暂停该组，不接受用整页替代单卡。Blazor Server 先作为技术候选，真实平板浏览器实测通过后再定（不限定 Safari：iPad、安卓平板用设备上可用的浏览器，不要求安装 App）。单卡及规整网格裁切提前纳入一期，个人卡包、投票、角色本分阶段解锁和私聊留到后续。

## 覆盖范围与代价

2026-10-21 后续确认：保留二维码与可复制网址两个入口，同一局所有玩家使用同一入口后自行认领角色。角色本改为使用导入识别文字排成“文库纸页”电子书，支持章节、翻页、字号和行距、专注及按文本位置恢复。原稿保留为核对入口，插图保留在原有位置；不改写、不概括、不补写。网页外壳沿用 WPF 的 Paper、Ink、Rule、Seal 配色和控件用语，正文使用适合长文的宋体，不重做 WPF 界面。原先统一转图片作为角色本主阅读方式的建议被覆盖，线索卡仍显示单张原图。原稿页与阅读器页码分别表示，字体不依赖外部 CDN。

当前仅实现合成材料探针和文字阅读器；完整冻结包接入、WPF 同进程控制、正式二维码入口、公共消息同步与真实平板验收仍未完成。不能把原生 PDF 合成测试或二维码辅助脚本自校验当作这些能力已经通过。

本决定局部取代 ADR 0001 的“不做平板联网、成员认证、跨设备同步”，允许本局轻量浏览器会话，不引入账号系统。交接文档 8.3 的卡片三态、环节分配及前提确认不再是当前需求。玩家可以提前打开卡片，何时点击由玩家遵循规则，程序负责点选对应准确及资产完整。

角色本进入主持模型的规则见 [ADR 0011](0011-dm-reads-whole-script.md)。真相对象、模型备忘、物理路径和密钥不进入平板接口；组织者手册原稿页后来改为只经已认领会话的手册接口提供（见 [ADR 0009](0009-tablet-handbook-tab.md)）。电脑既有推进、投票和揭秘约束保持原职责，浏览卡片不改变这些状态。

宪章升为 5.0.0，原因是设备边界和卡片访问约束发生不兼容变化。详细契约、实施顺序和验收见 [一期方案](../plans/2026-10-21-tablet-distribution.md)。尚未完成的技术验证不得表述为已上线或已可用。
