# Tablet distribution contract

进程内局域网 HTTP 契约，服务默认关闭。电脑点击「开启平板分发」后才绑定所选局域网 IPv4 与端口；
停止服务、切换本局或重启后旧加入令牌与浏览器会话作废。局域网一期使用 HTTP 与本地 IP，不要求安装证书。
平板浏览器不限定品牌：iPad、安卓平板用各自设备上可用的浏览器即可，不要求安装 App，不要求指定品牌。

通用约定：客户端不接收物理路径、完整来源集合、完整 ScriptPackage、truth 对象或密钥。本人角色本的原文只经专用阅读接口提供，不进入公共投影。组织者手册只以原稿页图片经 `GET /tablet/handbook/source/{页}` 提供给已认领角色的会话（无会话、未认领、页号越界均 404），不进入公共投影与卡目录（ADR 0009）。
错误码：会话无效 401，未认领角色访问角色本 403，ID 或页号不存在 404，组未准备好 409，角色认领冲突 409。
UI 只显示可理解提示，不显示异常堆栈与私有路径。

卡片分发规则：卡片全部按名称列出，玩家点哪张就提供对应单张卡面图片，没有按环节解锁，不设前提确认、领取次数或独占；旧游戏状态规则保持不变。
拆分失败或配对不可靠时暂停该组分发，明确显示未准备好（409），不以整页图片替代单张。

## POST /tablet/join

输入：本次服务加入令牌，二维码与网址指向同一本局加入入口，玩家任选一种进入后自行认领角色。
输出：本局浏览器会话 Cookie、本局公开标题与角色列表。
校验：服务已启用；令牌仍属于当前局。不建设账户、设备绑定或电脑审批。

## POST /tablet/role

输入：roleId。
输出：本人角色与角色页数量。
校验：角色存在；同时认领冲突返回 409，页面刷新角色列表。已认领角色可主动退出后重新选择。

## GET /tablet/catalog

输出：全部卡片 ID、公开名称、分组、编号与准备状态。
校验：本局会话有效。不含卡面或卡面缩略图，不按当前环节过滤。卡片全部按名称列出，点哪张给哪张。

## GET /tablet/cards/{cardId}/front

输出：对应单张卡图片（HTTP 图片响应）。
校验：当前冻结清单中存在且该组已准备好；不检查环节，不记录领取次数或独占。
取图按 cardId 与冻结资产索引解析，不按显示名称拼路径；同名卡不得模糊命中取第一张。
拆分失败或组未准备好时返回 409，不以整页图片替代单张。

## GET /tablet/role/book

输出：本人角色的原文章节、块、插图和来源映射；不经模型改写。网页按屏幕和字号分页。
校验：从本局浏览器会话确定角色，不接受客户端指定他人角色。正文不进入主持模型。

## GET/POST /tablet/role/progress

按本人会话保存 UTF-16 文本偏移与字号、行距、专注设置。位置 0 有效，不只保存页码；换角色清除旧角色进度。

## GET /tablet/role/source/{pageNumber}

输出：本人角色对应原稿页图片，仅供核对，不作为默认文字阅读方式。
校验：从 Cookie 的角色解析页码；客户端不能传别人的角色或任意文件路径，越界返回 404。响应带有 Cache-Control: no-store。

## GET /tablet/public?after={sequence}

输出：当前环节、公开消息列表及下一序号。
校验：按本局 ID 与单调序号去重；接入 HostViewModel.AddMessage 公共显示出口与已提交环节变化，由同一个 SessionStore 写入 SQLite；不含模型备忘（DmConversationSnapshot），不含 truth 或私有段。
公开消息保存失败时显示同步异常并停止累加，提供重试。公开消息恢复不触发 TTS。

## 传输与恢复

图片按页、按卡加载，通过 HTTP 图片响应传输，不 Base64 进连接消息，不一次下载全部角色本或全部卡面。
角色数据及原稿响应设置 Cache-Control: no-store，避免切角色后误复用同一路径下的旧内容。
普通网页刷新保持当前有效会话；断线后显示连接状态并提供刷新入口，刷新后回到本局和本人角色，不自动重发电脑操作。
停止服务后旧页面请求立即失败，旧请求不能误取新局同号卡。

## 禁用项

不开放目录浏览与任意文件下载；不监听公网地址；不配置路由器端口转发；
电脑的设置、模型密钥和存档不属于任何网页下载入口；手册只有上面的原稿页接口。
翻卡和浏览角色本不写入公共对话、AI 历史或游戏事件，也不改变本局 revision、阶段或材料释放，不触发 TTS。
旧游戏状态规则、推进、投票汇总与揭秘流程完全保持原有业务职责。

## 当前探针与目标合同的差距

当前 `/tablet/claim` 对应目标认领操作，`/tablet/release` 释放角色。浏览器会话由合成服务发放，没有正式 `/tablet/join` 加入令牌流程；匿名或未认领角色的数据请求暂返回 404，尚未完成目标的 401/403 分类。公共对话为固定合成列表，没有真实 `/tablet/public` 同步；服务独立运行，尚未由 WPF 控制。以上差距不能随合成阅读器验收而标为完成。
