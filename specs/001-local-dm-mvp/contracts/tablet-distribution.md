# Tablet distribution contract

进程内局域网 HTTP 契约，服务默认关闭。电脑点击「开启平板分发」后才绑定所选局域网 IPv4 与端口；
停止服务、切换本局或重启后旧加入令牌与浏览器会话作废。局域网一期使用 HTTP 与本地 IP，不要求安装证书。

通用约定：客户端不接收物理路径、SourceSpan 原文、完整 ScriptPackage、组织者手册、truth 对象或密钥。
错误码：会话无效 401，未认领角色访问角色本 403，ID 或页号不存在 404，组未准备好 409，角色认领冲突 409。
UI 只显示可理解提示，不显示异常堆栈与私有路径。

## POST /tablet/join

输入：本次服务加入令牌（二维码内容）。
输出：本局浏览器会话 Cookie、本局公开标题与角色列表。
校验：服务已启用；令牌仍属于当前局。不建设账户、设备绑定或电脑审批。

## POST /tablet/role

输入：roleId。
输出：本人角色与角色页数量。
校验：角色存在；同时认领冲突返回 409，页面刷新角色列表。已认领角色可主动退出后重新选择。

## GET /tablet/catalog

输出：全部卡片 ID、公开名称、分组、编号与准备状态。
校验：本局会话有效。不含卡面或卡面缩略图，不按当前环节过滤。

## GET /tablet/cards/{cardId}/front

输出：对应单张卡图片（HTTP 图片响应）。
校验：当前冻结清单中存在且该组已准备好；不检查环节，不记录领取次数或独占。
取图按 cardId 与冻结资产索引解析，不按显示名称拼路径；同名卡不得模糊命中取第一张。

## GET /tablet/role/pages/{pageNumber}

输出：本人角色对应页图片。
校验：从 Cookie 的角色解析页码；客户端不能传别人的角色或任意文件路径，越界返回 404。

## GET /tablet/public?after={sequence}

输出：当前环节、公开消息列表及下一序号。
校验：按本局 ID 与单调序号去重；不含模型备忘，不含 truth 或私有段。

## 传输与恢复

图片按页、按卡加载，不 Base64 进连接消息，不一次下载全部角色本或全部卡面。
普通网页刷新保持当前有效会话；断线后显示连接状态并提供刷新入口，刷新后回到本局和本人角色，不自动重发电脑操作。
停止服务后旧页面请求立即失败，旧请求不能误取新局同号卡。

## 禁用项

不开放目录浏览与任意文件下载；不监听公网地址；不配置路由器端口转发；
电脑的手册、设置、模型密钥和存档不属于任何网页下载入口。
翻卡和浏览角色本不写入公共对话、AI 历史或游戏事件，也不触发 TTS。
